Simon Willison 创建了一个交互式 SQLite 查询解释器工具，该工具使用 Pyodide（一个用于 WebAssembly 的 Python 发行版）完全在浏览器中运行。该工具为 EXPLAIN 和 EXPLAIN QUERY PLAN 的输出提供了人类可读的解释。 理解 SQLite 查询计划是开发者的常见痛点，而该工具通过提供通俗易懂的解释降低了门槛，且无需任何安装配置。它展示了通过 WebAssembly 在浏览器中运行 Python 来构建实用开发者工具的能力。 该工具通过 Pyodide 在浏览器内的 WebAssembly 中运行 Python，进而运行 SQLite。Willison 提到他借助 AI 工具 Fable 构建了它，并提醒说他自己并非 SQLite 查询计划专家，因此解释应谨慎使用。
