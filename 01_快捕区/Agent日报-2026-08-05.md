## [Deno 推出 Celld：自托管持久对象，基于 SQLite](https://github.com/denoland/celld) ⭐️ 8.0/10

Deno 发布了 Celld，这是一个开源守护进程，可以在你自己的机器上运行 Cloudflare Workers 和持久对象。每个对象由独立的 SQLite 数据库支持，并复制到你拥有的 S3 兼容存储桶中，无需控制平面或共识机制。 这打破了持久对象（Durable Objects）的供应商锁定，此前这一关键抽象仅与 Cloudflare 绑定。它使开发者能够在自己基础设施上运行分布式有状态应用，可能大幅降低成本，并为边缘计算开辟新的部署选项。 Celld 是一个 58 MB 的静态可执行文件，可通过 curl 或 Docker 安装。节点仅通过 S3 存储桶进行协调，无需控制平面或共识机制，且支持的 API 代码可原样运行。

hackernews · calvinfo · 8月5日 16:50 · [社区讨论](https://news.ycombinator.com/item?id=49185430)

**背景**: 持久对象是 Cloudflare Workers 的一项功能，提供具有唯一 ID 的强一致有状态对象，用于协调和存储。Celld 通过使用 SQLite 存储本地状态、S3 进行复制，将这一模型扩展到自托管环境，类似于 Verneuil 等方法。这使得开发者无需绑定 Cloudflare 基础设施即可使用持久对象 API。
