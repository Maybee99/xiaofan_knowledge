## [Firefox 被编译为 WebAssembly 并在另一浏览器中运行](https://simonwillison.net/2026/Jul/16/firefox-in-webassembly/#atom-everything) ⭐️ 9.0/10

Puter 将完整的 Firefox 浏览器（Gecko 引擎）编译为 WebAssembly，使其能够在 Chrome 等另一浏览器中运行。该项目使用了价值约 25,000 美元的 Claude Opus 和 Fable 代币，但由于订阅计划，实际花费少得多。 这一突破表明，即使是浏览器这样的复杂原生应用也可以移植到 Web 平台，可能为安全的浏览器隔离和基于 Web 的沙箱计算等新用例铺平道路。同时，它也展示了 AI 辅助编程在大规模移植工作中的潜力。 该演示使用 Wisp 协议将所有网络流量通过 Puter 的服务器进行代理，因为 WebAssembly 代码无法打开任意网络连接。该项目声称支持端到端加密，检查确认 HTTPS 流量保持加密，而 HTTP 流量可见。

rss · Simon Willison · 7月16日 23:34

**背景**: WebAssembly \(WASM\) 是一种低级二进制指令格式，可在现代浏览器中以接近原生的速度运行。将 Firefox 这样的完整浏览器编译为 WASM 是一项艰巨的任务，因为浏览器引擎包含渲染、JavaScript 执行和网络等复杂功能。Puter 选择 Firefox 是因为其强大的单进程支持，简化了移植工作。

## [首次在宜居带岩石系外行星发现大气层](https://www.bbc.com/news/articles/cy4kdd1e0ejo) ⭐️ 8.0/10

詹姆斯·韦伯太空望远镜在 LHS 1140b 的大气层中探测到氦气，这是一颗距地球 48 光年、位于红矮星宜居带的岩石超级地球。这是首次在相对类似地球的宜居带系外行星上确认存在大气层。 这一发现是系外行星科学的一个里程碑，表明红矮星宜居带内的岩石行星即使在强烈的恒星辐射下也能保留大气层。它为研究此类世界的潜在宜居性以及寻找生物特征信号打开了大门。 LHS 1140b 的质量约为地球的 5.6 倍，半径约为地球的 1.7 倍，属于超级地球类别。氦气的探测表明该行星可能是一个海洋世界，其质量的 9-19%由水组成，而非纯岩石行星。

hackernews · neversaydie · 7月17日 14:06 · [社区讨论](https://news.ycombinator.com/item?id=48947560)

**背景**: 红矮星是小型、低温的恒星，比太阳暗淡得多，因此它们的宜居带非常靠近恒星。这些区域内的行星通常被潮汐锁定，并受到强烈的恒星耀斑影响，使得大气层的保留变得困难。詹姆斯·韦伯太空望远镜（JWST）是一个强大的红外天文台，能够通过行星凌星时的透射光谱分析系外行星的大气成分。

## [开源 AI 模型崛起，威胁闭源领导者](https://stateofopensource.ai/) ⭐️ 8.0/10

开源 AI 模型市场份额迅速增长，目前在 OpenRouter 上处理的 token 占比达 63%，而四个月前仅为 40%，同期每日 token 处理量增长了近 5 倍。 这一转变威胁到 OpenAI 和 Anthropic 等闭源模型公司，因为开源模型为超大规模云服务商和设备制造商提供了成本优势和灵活性，可能重塑 AI 行业格局。 来自 OpenRouter 的数据显示，开源模型最近一天处理了 4.19 万亿个 token，而 2025 年 3 月 19 日为 8880 亿，四个月内增长了 5 倍。

hackernews · rellem · 7月17日 14:31 · [社区讨论](https://news.ycombinator.com/item?id=48947825)

**背景**: 开源 AI 模型以宽松许可证公开提供，允许任何人免费使用、修改和部署，无需支付许可费。这与 OpenAI 等公司的闭源模型形成对比，后者通过 API 访问并通常需要订阅费用。开源模型的增长得益于其成本效益以及在本地硬件上运行的能力。

**社区讨论**: 评论者意见不一：有人认为开源模型将凭借成本和灵活性优势淘汰闭源 AI 公司，而另一些人则批评该分析由 LLM 生成且缺乏深度。有用户构建了追踪 OpenRouter 数据的仪表盘来支持增长说法。
