# Codex 使用笔记

> Codex 是一个基于 GPT-5 的 AI 编程助手，能与开发者深度协作完成编码、调试、知识管理等任务。

## 基本信息

- **全称**：Codex（桌面版）
- **定位**：自主编程 Agent，不只是聊天的 AI 工具
- **核心能力**：阅读代码库、文件读写、执行命令、调用 MCP 工具、自动修复、主动推进任务
- **运行环境**：桌面应用（Windows/macOS），附带有沙箱执行环境

## 核心特点

### 持续协作
Codex 不会只给个方案就停下来，而是直接去做——改代码、跑命令、调试循环，直到任务真正完成。

### 上下文感知
- 自动读取项目结构，理解代码库的已有模式
- 工程判断：复用已有框架、遵循项目约定、不随意引入新风格
- 从代码里学习怎么做，而不是从零猜

### 自主性
- 遇到问题会自己尝试解决，不轻易退还给用户
- 支持持久化工作（启动 dev server、跑测试、安装依赖）
- 只在真正受阻时礼貌地请求帮助

## 使用场景

| 场景 | 说明 |
|------|------|
| **功能开发** | 从需求到实现，自动完成多文件改动 |
| **代码审查** | 按严重等级列出问题、风险、测试缺口 |
| **调试排查** | 阅读日志、定位错误、给出修复方案 |
| **知识库管理** | 整理笔记、建立链接、维护结构 |
| **自动化任务** | 写脚本、配置 CI/CD、批量操作 |

## 使用技巧

1. **给够上下文**：描述清楚"我现在在做什么 + 我想达到什么效果"，Codex 会做得更好
2. **别怕打断**：中途可以纠正方向，Codex 会按最新指令调整
3. **利用 MCP 工具**：Codex 可以调用外部工具（数据库、API、文档搜索），功能可扩展
4. **沟通风格**：保持自然中文沟通即可，它理解语境和情绪

## 注意事项

- 编辑文件时不会擅改未提及的代码
- 在 Git 工作区中不会随意 revert 用户的改动
- 遇到需要权限的操作会询问后再执行
