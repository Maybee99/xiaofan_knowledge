## 二、项目背景

面向 ToB 场景的 AI 销售助手平台 Herness，核心目标是通过 Multi-Agent 架构拆解销售协作任务，提升销售人效。我在团队中负责多个子 Agent 的开发与编排工作。

## 三、主要职责与成果

### 1. Multi-Agent 架构设计

- 基于 Herness 产品定位，设计 Multi-Agent 协作架构，进行任务拆解
- 将销售工作流拆分为文件 Agent、CRM Agent、方案 Agent 三个子 Agent，各司其职又协同工作
- 使用 LangGraph 进行 workflow 编排，确保消息在 Agent 之间有序流转

### 2. 客户档案模块

- 设计 Cron 定时任务，每日自动拉取昨日 CRM 客户与跟进记录
- Agent 对客户数据做智能解析，构建客户画像
- 生成按优先级排序的今日推荐拜访脑图，帮助销售快速锁定高价值客户

### 3. CRM 跟进模块

- Agent 采用 ReAct 模式，解析销售人员的语音输入
- 结合 Web 搜索工商信息，实时决策补全 CRM 所需字段
- 生成跟进记录后触发 Reflection 自检机制，确保内容准确无误后再写入 CRM 系统
- **成果**：销售人效提升约 25%

### 4. 方案生成模块

- 主 Agent 采用 Plan-and-Solve 策略规划方案生成任务
- 子 Agent 结合客户档案、痛点及竞品数据，自动编排内容结构
- 支持输出 HTML / MD 格式的在线方案
- **成果**：方案产出周期从平均 1 小时压缩至 10 分钟，并支持版本留存与二次修改

## 四、收获与反思

- **技术成长**：深入实践了 Multi-Agent 架构、ReAct 模式、Plan-and-Solve 策略和 Reflection 自检机制，对 LangGraph 的 workflow 编排有了扎实的理解
- **工程感知**：ToB 产品对稳定性和数据准确性要求极高，自检和异常处理机制必不可少
- **产品思维**：理解了销售业务场景下的真实痛点——效率低、信息分散、方案定制耗时，Agent 在这些环节的价值非常直接
