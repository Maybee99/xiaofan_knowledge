## 二、项目背景

参与中国石油数字化平台的数据仓库建设，负责 AI 相关模块从调研到落地的全流程开发。团队聚焦能源领域的数据智能，包括文档知识管理、预测建模与数据治理。

## 三、主要职责与成果

### 1. 智能文档问答系统（RAG）

- **背景**：能源领域存在大量淘汰产品文档，技术人员查找效率低、知识分散
- **方案**：基于 DeepSeek-r1 大模型 + LangChain 框架构建 RAG 知识库系统
- **实现细节**：
  - PDF 解析与文本向量化，构建向量索引
  - 设计 Embedding 语义切分与混合检索策略
  - 结合文档置信度判断，提升检索准确性
- **成果**：文档问答准确率达 92%

### 2. 油井腐蚀度预测模型

- **背景**：油井管道的腐蚀度预测对安全生产和运维规划至关重要
- **方案**：基于 PyTorch 搭建 LSTM + 注意力机制模型
- **技术手段**：
  - 特征工程：对历史腐蚀数据进行特征提取与筛选
  - 早停（Early Stopping）与梯度裁剪（Gradient Clipping）
  - 注意力机制增强关键时序特征的权重
- **成果**：显著提升预测精度与泛化能力

### 3. 数据溯源与平台开发

- **背景**：数据仓库中 1000+ 条 SQL 语句的源表依赖关系复杂，手工溯源困难
- **方案**：开发 Python 脚本自动解析 SQL 语句，提取源表依赖关系图谱
- **部署**：Docker 容器化部署，确保环境一致性和可迁移性
- **成果**：SQL 溯源准确率达 98%

## 四、收获与反思

- **RAG 落地经验**：从理论到落地走通了 RAG 的全流程——文档解析、向量化、检索策略、置信度判断，对 RAG 的优缺点有了切身理解
- **模型工程**：LSTM + Attention 的调参过程让我深刻体会到特征工程和正则化策略的重要性
- **数据处理能力**：面对千级 SQL 的批量解析，锻炼了处理复杂真实数据的工程能力
- **行业感受**：能源领域的 AI 应用场景非常务实，对准确率要求极高，"能用"和"好用"之间差距很大
